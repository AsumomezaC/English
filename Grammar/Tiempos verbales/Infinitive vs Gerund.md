# Infinitive vs Gerund
## Use -ing
- como el sujeto de una oración 
- Después de una preposición 
- Después de ciertos verbos:
	- avoid
	- enjoy
	- finish
	- hate
	- keep
	- like
	- love
	- (don't) mind
	- prefer
	- recommend
	- spend time
	- stop
	- etc
## to verb
- expresar propósito 
- después de *be + adjetive*
- después de *what, where, when, why, how, etc.*
- Después de ciertos verbos:
	- decide
	- forget
	- help
	- hope
	- learn
	- need
	- offer
	- plan
	- promise
	- Remember
	- seem
	- try
	- want
	- would + *verb*
